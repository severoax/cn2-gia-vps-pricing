## 购买前需要留意的限制

### 1. CN2 GIA不等于固定低延迟

线路优化可以改善网络路径，但无法保证每个地区、每个运营商、每个时间段都一样。不要只看宣传中的线路名称，最好根据自己的用户来源、运营商和目标服务判断。

### 2. VPS是自主管理服务

官方页面明确标注为 self-managed。你需要自己处理：

- Linux 系统更新；
- SSH 密钥和密码安全；
- Web 服务配置；
- 数据库维护；
- 防火墙规则；
- 日志清理；
- 网站和数据备份；
- 异常流量和资源占用。

如果不熟悉 Linux，建议先从 20G 或 40G 套餐开始，避免一上来购买高配方案却没有维护能力。

### 3. 月流量用完可能影响服务

每个方案都包含固定月流量额度。流量较大的下载站、图片站、视频站和文件同步服务，应重点计算出站流量。端口带宽再高，如果月流量额度不足，实际使用仍然会受到限制。

### 4. IP与网络环境会变化

海外 VPS 的 IP 可能受到滥用、扫描、攻击或历史使用情况影响。即使同一套餐、同一机房，不同 IP 的访问表现也可能存在差异。不要把某一次测试结果当成永久保证。
